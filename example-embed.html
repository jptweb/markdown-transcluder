Usage Instructions

For MyCourses Integration:

  1. Upload Files: Upload github-proxy.php, config.php, and the vendor/ folder to your web server.
  2. Configure: Edit config.php with your GitHub token and settings.
  3. Install Dependencies: Run composer install on your server.
  4. Add to MyCourses: In MyCourses, create an HTML content item and paste:
<!-- Include CSS -->
<link rel="stylesheet" href="https://your-domain.com/path/to/github-embed.css">

<!-- Include JavaScript -->
<script src="https://your-domain.com/path/to/github-embed.js"></script>

<!-- GitHub Notes Widget -->
<div class="github-notes"
     data-repo="your-username/your-repo"
     data-file="notes/your-file.md"
     data-proxy-url="https://your-domain.com/path/to/github-proxy.php">
</div>

Required Data Attributes:

  • data-repo: Your GitHub repository in format "username/repo-name"
  • data-file: Path to the file in your repository

Optional Data Attributes:

  • data-proxy-url: Custom URL to your proxy service
  • data-auto-refresh="true": Enable automatic content refresh
  • data-refresh-interval="300": Refresh interval in seconds
  • data-loading-text: Custom loading message
